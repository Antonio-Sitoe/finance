
# Folder Structure — Package by Feature

```
src/main/java/com/financeiro
```

---

## Global Packages

### config/

Cross-cutting system configurations.

```
SecurityConfig
CorsConfig
OpenApiConfig
```

### exception/

Global error handling.

```
ResourceNotFoundException
BusinessException
GlobalExceptionHandler
```

### util/

Shared utility classes.

```
DateUtil
ValidatorUtil
```

## Business Modules

All modules live inside the `modules/` package. Each module contains its own sub-folders by layer:

### modules/client/

```
modules/client/
├── controller/
│   └── ClientController
├── service/
│   └── ClientService
├── repository/
│   └── ClientRepository
├── model/
│   └── Client
├── dto/
│   ├── ClientRequestDTO
│   └── ClientResponseDTO
└── mapper/
    └── ClientMapper
```
