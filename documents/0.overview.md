# Finance — Sistema de Gestão Financeira

## Sobre o Projecto

O **Finance** é um sistema web de gestão financeira empresarial. O seu objectivo é permitir que empresas controlem as suas finanças de forma centralizada — gerindo clientes, fornecedores, contas bancárias, categorias de receitas e despesas, e lançamentos financeiros com suporte a parcelamento.

O sistema oferece uma visão clara do fluxo de caixa, dashboards com indicadores financeiros e relatórios exportáveis, ajudando na tomada de decisão.

---

## Objectivo

Fornecer uma plataforma completa para:

- Registar e acompanhar receitas e despesas
- Gerir clientes, fornecedores e contactos
- Controlar contas bancárias e categorias financeiras
- Criar lançamentos com parcelamento automático
- Visualizar o fluxo de caixa e saldo por período
- Gerar relatórios financeiros por categoria, cliente e período

---

## Módulos do Sistema

| Módulo                  | Descrição                                                        |
| ----------------------- | ---------------------------------------------------------------- |
| **Autenticação**        | Login com JWT, gestão de usuários e perfis (ADMIN / USER)        |
| **Dashboard**           | Indicadores financeiros, gráficos de despesas, receitas e saldo  |
| **Clientes**            | CRUD de clientes empresariais com CNPJ, endereço e nota          |
| **Contactos**           | Contactos vinculados a clientes (nome, CPF, departamento)        |
| **Fornecedores**        | CRUD de fornecedores com dados fiscais e endereço                |
| **Contas**              | Contas bancárias / caixa (agência, conta corrente, observações)  |
| **Categorias**          | Categorias hierárquicas de receita e despesa (com subcategorias) |
| **Lançamentos**         | Módulo principal — registo de receitas/despesas com parcelamento  |
| **Fluxo de Caixa**      | Visualização de movimentações, saldo inicial/final, entradas/saídas |
| **Relatórios**          | Relatórios por período, categoria e cliente, com exportação CSV/Excel |
| **Pesquisa Global**     | Busca rápida de clientes, fornecedores e lançamentos             |

## Modelo de Dados

O sistema é composto por 6 entidades principais:

- **Cliente** — empresa com CNPJ, endereço e dados de contacto
- **Contacto** — pessoa vinculada a um cliente (nome, CPF, departamento)
- **Fornecedor** — empresa fornecedora com dados fiscais e endereço
- **Conta** — conta bancária ou caixa (agência, conta corrente)
- **Categoria** — classificação hierárquica de receitas/despesas (com categoria pai)
- **Lançamento** — registo financeiro com valor, parcelas, datas, categoria, conta, cliente e fornecedor

### Enums

- `situacao_enum` — ATIVO / INATIVO (usado em clientes, fornecedores, contas, categorias, contactos)
- `pagamento_enum` — PAGO / PENDENTE (usado em lançamentos)

---

## Funcionalidades Transversais

- **Paginação e ordenação** em todas as listagens
- **Filtros avançados** por nome, CNPJ, data, categoria, cliente, fornecedor, conta e status
- **Auditoria** com campos created_at, updated_at e created_by
- **Validações** no backend (CNPJ obrigatório, valor > 0, email e CPF válidos)
- **Tratamento global de erros** com respostas padronizadas
- **Controlo de acesso** por perfil (ADMIN tem acesso total, USER acede ao módulo financeiro)
