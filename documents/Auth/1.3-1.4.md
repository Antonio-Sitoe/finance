## 1.3 — Entidades e repositórios de tokens

### Modelos (`modules/auth/model/`)

- `RefreshToken` → tabela `refresh_token`
- `PasswordResetToken` → tabela `password_reset_token`
- Ambos estendem `BaseEntity`, com `usuario` (`@ManyToOne` LAZY), `tokenHash`, `expiresAt`
- `RefreshToken.revokedAt` / `PasswordResetToken.usedAt`

### Repositórios (`modules/auth/repository/`)

- `RefreshTokenRepository`: `findByTokenHash`, `findAllByUsuarioIdAndRevokedAtIsNull`
- `PasswordResetTokenRepository`: `findByTokenHash`

### Correcções

| Problema | Correcção |
| -------- | --------- |
| `@Table` no plural (`refresh_tokens` / `password_reset_tokens`) | Alinhado com V3: `refresh_token` / `password_reset_token` |
| Flyway Boot 4 silencioso (só `flyway-core`) | `spring-boot-starter-flyway` no `pom.xml` |
| V3 falhava ao reaplicar (`ultimo_acesso` já existia) | V3 idempotente (`IF NOT EXISTS`) |

## 1.4 — JwtService

`modules/auth/security/JwtService.java`

- Lê `jwt.secret` e `jwt.access-ttl-minutes`
- `gerarAccessToken(Usuario)` — subject = id, claims `email` + `role` (= `perfil.name()`)
- `validar(token)` — JJWT 0.11.5 `parserBuilder()`
- `Usuario` importado de `modules.usuario.model` (não de `auth.model`)
