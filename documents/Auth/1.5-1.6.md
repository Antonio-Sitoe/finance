## 1.5 — AuthService + AuthController

### Pré-requisitos feitos

- `UsuarioRepository.findByEmail(String)`
- `Usuario.ultimoAcesso` (`LocalDateTime`, nullable — alinhado com V3)
- `UsuarioService.validarEmailUnico` público
- `MeUpdateRequestDTO(nome, email)`

### `AuthService`

| Método | Função |
| ------ | ------ |
| `login` | email+senha → access JWT + refresh (hash na BD) |
| `refresh` | rotação do refresh |
| `logout` | revoga refresh (idempotente) |
| `me` / `atualizarMe` | perfil + PATCH nome/email |
| `changePassword` | senha actual + nova + confirmação |
| `forgotPassword` / `resetPassword` | stubs → lógica real no **1.9** |

### `AuthController` (`/api/auth/...`)

login, refresh, logout, me, PATCH me, change-password, forgot-password, reset-password

### Review / correcções

| Problema | Correcção |
| -------- | --------- |
| `atualizarMe` não gravava email | `u.setEmail(dto.getEmail())` |
| Refresh TTL hardcoded `30` | usa `jwt.refresh-ttl-days` |
| `ultimoAcesso` `nullable=false` vs V3 | campo nullable |
| `@Transactional` jakarta | Spring `@Transactional` |

## 1.6 — Filtro JWT + SecurityConfig

- `JwtAuthenticationFilter` — Bearer → `SecurityContext` (`sub` = userId, `ROLE_{perfil}`)
- `SecurityConfig` — uma única chain: públicos (login/refresh/forgot/reset + swagger/actuator); resto `authenticated()`; sessão `STATELESS`

### Checkpoint curl

```bash
curl -i http://localhost:8081/api/usuarios                          # 401
curl -X POST http://localhost:8081/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"...","senha":"..."}'                               # tokens
curl http://localhost:8081/api/auth/me -H "Authorization: Bearer $TOKEN"
```
