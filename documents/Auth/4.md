# Sprint 4 — Endurecer ✅

## Entregue

| Item | Implementação |
|------|----------------|
| Rate limit | `AuthRateLimitFilter` — 5 POST/min em `/api/auth/login` e `/forgot-password` |
| Cookie refresh | `RefreshTokenCookieSupport` — HttpOnly, SameSite=Strict, path `/api/auth` |
| Login body | só `accessToken`; refresh no cookie |
| Último ADMIN | `countActiveAdminsExcluding` em desactivar / toggle / update role |
| Access em memória | Angular: sem `sessionStorage`; F5 → `refresh()` + `loadMe()` |
| `withCredentials` | interceptor em todos os pedidos API |

## Config

```yaml
auth:
  cookie:
    secure: ${AUTH_COOKIE_SECURE:false}  # true em HTTPS/produção
```
