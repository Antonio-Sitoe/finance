# Passo 1.9 — feito (forgot/reset)

Sprint 1 completo no backend. Guia activo: [24](../24%20-%20Auth%20CRUD%20-%20Guia%20de%20implementação.md) no **Sprint 2**.

## Comportamento

### `forgotPassword`
- Se email inexistente ou user inactivo → **200 sem efeito** (não revela)
- Se ATIVO → invalida tokens anteriores, cria token (32 bytes Base64URL, hash SHA-256, expira em 1h)
- **Imprime o link no log** (sem SMTP):

```
Link de reset de senha para admin@finance.com: http://localhost:4200/reset-password?token=...
```

### `resetPassword`
- Valida token (existe, não usado, não expirado) + confirmação da senha
- Grava nova senha (BCrypt)
- Marca token `usedAt`
- Revoga todos os refresh tokens do user

## Teste

1. UI forgot ou `POST /api/auth/forgot-password` com `{"email":"admin@finance.com"}`
2. Copiar URL do log do backend
3. Abrir no browser → nova senha → login
