
# ✅ Project Setup & Configuration

### Backend Setup
* [x] Create a new Spring Boot project (use Spring Initializr)
* [x] Set Java version (17+ recommended)
* [x] Choose build tool: Maven or Gradle

### Dependencies
* [x] Spring Web
* [x] Spring Data JPA
* [x] PostgreSQL Driver
* [x] Validation
* [x] Lombok
* [x] Spring Security (for authentication)
* [x] JWT (for token-based auth)

### Database (Recommended: Docker)
* [x] Configure application properties (port, DB connection, etc.)
* [x] Set up PostgreSQL using Docker
* [x] Configure database user/password
* [x] Create initial schema (can use provided SQL)


### Tools
* [x] Install Java 17+ (JDK)
* [x] Install Maven or Gradle
* [x] Install Docker (for DB)
* [x] Install Postman or Insomnia (for API testing)
* [x] Recommended IDE: IntelliJ IDEA or VS Code
