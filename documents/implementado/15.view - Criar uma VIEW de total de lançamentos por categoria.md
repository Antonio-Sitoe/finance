- [x] **4. Criar uma VIEW de total de lançamentos por categoria**

**Objetivo:** Consolidar valores financeiros.
**Tarefa:**
Crie uma view que mostre:

- nome da categoria
- quantidade de lançamentos
- soma total dos valores

Agrupe por categoria.

```sql
CREATE OR REPLACE VIEW vw_lancamentos_por_categoria AS
SELECT
    c.nome AS nome_categoria,
    COUNT(l.id) AS quantidade_lancamentos,
    COALESCE(SUM(l.valor), 0) AS soma_total
FROM categoria c
LEFT JOIN lancamentos l
    ON l.id_categoria = c.id
GROUP BY
    c.id,
    c.nome;
```
