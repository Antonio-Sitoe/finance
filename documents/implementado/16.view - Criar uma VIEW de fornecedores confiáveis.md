- [x] **5. Criar uma VIEW de fornecedores confiáveis**

**Objetivo:** Criar lista filtrada por regra de negócio.
**Tarefa:**
Crie uma view chamada `vw_fornecedores_confiaveis` que contenha:

- id
- nome
- nota
- tipo (ex: “bom”, “excelente”, “ruim”) → baseado em CASE
  - nota ≥ 4 → “excelente”
  - 3 ≤ nota < 4 → “bom”
  - nota < 3 → “ruim”

```sql
CREATE OR REPLACE VIEW vw_fornecedores_confiaveis AS
SELECT
    f.id,
    f.nome_empresarial AS nome,
    f.nota,
    CASE
        WHEN f.nota >= 4 THEN 'excelente'
        WHEN f.nota >= 3 THEN 'bom'
        ELSE 'ruim'
    END AS tipo
FROM fornecedor f;
```
