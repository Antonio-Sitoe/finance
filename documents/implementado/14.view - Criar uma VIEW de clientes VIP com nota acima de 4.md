- [x] **2. Criar uma VIEW de clientes VIP com nota acima de 4**

**Objetivo:** Filtrar clientes com nota alta.
**Tarefa:**
Crie uma view chamada `vw_clientes_vip` contendo:

- id
- nome
- nota
- estado

Somente para clientes onde `nota >= 4`.

---

```
CREATE VIEW vw_clientes_vip AS
  SELECT
   c.id,
   c.nome_empresarial as nome,
   c.nota,
   c.estado
 FROM clientes c
 WHERE c.nota >= 4
 ORDER BY c.nota

```
