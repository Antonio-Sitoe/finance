- [x] **1. Criar uma VIEW de clientes com seus contatos principais**

**Objetivo:** Consolidar informações do cliente e seu contato mais recente.
**Tarefa:**
Crie uma view que mostre:

- nome do cliente
- email do cliente
- número do contacto mais recente (maior `id`)

Utilize `JOIN` + subconsulta para pegar apenas o último contacto.

```
 CREATE VIEW Vv_contactos as
        SELECT
            emp.id,
            emp.nome_empresarial AS Empresa,
            ct.email,
            ct.nome,
            ct.telefone
        FROM clientes emp
        LEFT JOIN contactos ct
            ON emp.id = ct.cliente_id;

```
