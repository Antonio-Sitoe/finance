- [x] **3. Criar uma VIEW de saldo completo das contas**

**Objetivo:** Mostrar visão completa de contas com seus donos.
**Tarefa:**
Crie uma view que mostre:

- id da conta
- nome do cliente dono da conta
- saldo
- data de criação da conta

Use JOIN entre `conta` e `cliente`.

```
SELECT
    ct.id,
    ct.nome,
    cl.nome_empresarial AS cliente,
    ct.data_inclusao,
    SUM(
        CASE
            WHEN l.tipo = 'RECEITA' THEN l.valor
            WHEN l.tipo = 'DESPESA' THEN -l.valor
            ELSE 0
        END
    ) AS saldo
FROM lancamentos l
INNER JOIN contas ct
    ON l.id_conta = ct.id
INNER JOIN clientes cl
    ON l.id_cliente = cl.id
GROUP BY
    ct.id,
    ct.nome,
    cl.nome_empresarial,
    ct.data_inclusao;
```
